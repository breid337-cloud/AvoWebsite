    What this scan does

    Tier one is everything measurable from outside, without a client granting access to anything.

    Checked weekly

    • Home page answers, and how quickly
    • Certificate expiry and issuer, read off the TLS handshake
    • DNS records, and any change since last week
    • Page count from the sitemap
    • Lighthouse performance, accessibility, best practices and SEO
    • Old domains still redirecting

    Never done

    • No deploys and no edits to any client site
    • No DNS changes
    • Nothing published anywhere
    • There is no deploy path in the script to misfire

    Tier two, once clients allow it

    • New Google reviews, via Business Profile access
    • New Facebook and Instagram posts worth pulling onto the site
    • Search ranking movement
    • Each needs the client to add AvoSolution as a manager — Jackson's and K9 both still to ask
